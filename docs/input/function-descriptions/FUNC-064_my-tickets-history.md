# FUNC-064 My Tickets (History)

## Goal

Show historical used ticket records.

## Inputs

- Authenticated user identity
- Ticket records filtered by used status

## Behavior

1. Open history tab in My tickets page.
2. Display used ticket records with date/count/status.
3. Allow switching back to Unused tab (p63).

## Error Cases

- Ticket history API failure
- Unauthorized access
