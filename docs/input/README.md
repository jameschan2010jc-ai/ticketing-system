# Input Artifact Intake

Place incoming product/design artifacts in:

- UI images: `docs/input/ui-images/`
- Function descriptions: `docs/input/function-descriptions/`
- Page flows: `docs/input/page-flows/`

## Recommended Naming

- `PAGE-<id>_<short-name>.<ext>` for page assets
- `FUNC-<id>_<short-name>.md` for function descriptions
- `FLOW-<id>_<short-name>.png|md` for flow diagrams/text

## Next Step After Adding Inputs

1. Add rows to `docs/specs/requirements-traceability.md`.
2. Create page specs with `docs/specs/frontend-pages/page-spec-template.md`.
3. Create service specs with `docs/specs/backend-services/service-spec-template.md`.
