# FLOW-002 Purchase Method Selection

1. User lands on `/purchase-method` (p2).
2. User sees header title and three options.
3. If user chooses existing account login, system routes to `/login-existing-account` (p30).
4. If user chooses new account registration, system routes to `/register-method` (p40).
5. If user chooses direct purchase, system routes to `/purchase-method/guest-notice` (p3).
6. Home/Profile icons in bottom area navigate the same way as p1.
