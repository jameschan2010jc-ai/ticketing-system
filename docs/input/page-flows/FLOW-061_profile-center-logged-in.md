# FLOW-061 Profile Center (Logged-in)

1. User taps bottom Profile icon on any page.
2. System checks auth status.
3. If user is logged in, system routes to `/profile-center` (p61).
4. My orders routes to `/my-orders` (p62).
5. My tickets routes to `/my-tickets` (p63).
6. Change password routes to `/change-password` (p33).
7. Logout clears session and routes to `/` (p1).
